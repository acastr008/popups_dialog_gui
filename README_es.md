## Descripción

<name_project> es un sistema de gestión de formularios para introduccóon de datos por pantalla en una aplicación Pygame.  Tiene un diseño modular que permitirá ampliar fácilmente el desarrollo de nuevos tipos de contenedores y de widgets de todo tipo. 

Algunos de los widgets que ya se han desarrollado pueden justificar por si solos el uso de este módulo. 

## Estado del proyecto

Se ha desarrollado una considerable cantidad de funcionalidades, pero se ha avanzado mucho menos en cuidar los aspectos estéticos.  Estos aspectos estéticos recibirán mucho más atención en futuras versiones.

## Cómo ejecutar los programas de ejemplo (Quickstart).

En la raiz del proyecto existe un lanzador que visualiza la lista de programas de ejemplo disponibles acompañados de una breve descripción. 

Basta seleccionar uno de ellos y pinchar en él con el ratón para ejecurtalo. El comando para usar el lanzador es:

```bash
python main.py
```
