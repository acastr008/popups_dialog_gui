## Descripción

popups_dialog_gui es un **módulo de ventanas emergentes** (pop-up) usando Pygame para generar avisos, diálogos, etc.
También incluye posibilidades más avanzadas pensadas como base para ampliar funcionalidad (por ejemplo, ventanas de ayuda).
En breve se habilitará el uso de formularios, menús, etc.

## Estado del proyecto

Se ha desarrollado una cantidad considerable de funcionalidades y se ha complementado con documentación.
Desarrollado y probado en Linux. En otros sistemas puede funcionar, pero no está verificado.

## Ejemplos de uso

En el directorio `examples/` del proyecto hay una pequeña colección de programas para demostrar los diferentes usos de popups_dialog_gui.
Existe un tutorial que facilita el aprendizaje en el orden más adecuado y sirve de guía para comprender los conceptos introducidos en cada ejemplo.

## Cómo ejecutar los programas de ejemplo (Quickstart)

En la raíz del proyecto existe un lanzador (`main.py`) que muestra la lista de programas de ejemplo disponibles junto con una breve descripción.

Para probarlos en Linux puede descargar el lanzador y todo el directorio `examples/`. Asegúrese de tener instalado:

- python >= 3.9
- pygame >= 2.0
- help-core-pygame >= 0.1.2 (librería auxiliar Pygame del mismo autor)

El comando para usar el lanzador es:

```bash
python main.py
```

Basta seleccionar uno de los ejemplos y hacer clic con el ratón para ejecutarlo.
